# kenton-link-lens 故障排查

按“症状 → 原因 → 安全检查 → 修复 → 恢复验证”的顺序处理。

## 可用 Skill 列表中没有 `kenton-link-lens`

**常见原因**

- `kenton-link-lens` 目录没有放在宿主要求的 Skills 目录；
- 文件被多套了一层目录；
- 宿主仍在使用旧会话或缓存；
- 宿主不支持本项目采用的 `SKILL.md` 结构。

**安全检查**

确认目标目录中直接存在 `SKILL.md`，并且 frontmatter 中是：

```yaml
name: kenton-link-lens
```

**修复**

按宿主官方文档调整目录位置，然后重新启动宿主或开启新会话。

**恢复验证**

可用 Skill 列表中出现 `kenton-link-lens`，再发送一个无需登录的短网页链接进行测试。

## Agent 只给了摘要，没有三阶段分析

**常见原因**

- Skill 没有被实际加载；
- 请求只触发了宿主的通用摘要能力；
- Agent 没有完整读取链接内容。

**安全检查**

检查回答是否分别包含“读透证据、细分分析、结论与行动”。

**修复**

明确点名 Skill 和验收结构：

```text
请用 kenton-link-lens。先列出你实际读取的证据，再细分分析，最后给出判断、想法、方案和行动。
```

**恢复验证**

回答明确区分实际读到的内容与未确认项，并完成三个阶段。

## Agent 无法访问链接

**常见原因**

- 页面需要登录、地区权限或付费访问；
- 宿主没有浏览器或网络工具；
- 页面依赖脚本渲染、已删除或暂时不可用。

**安全检查**

不要提供 Cookie、token 或账号密码。确认你是否有权下载或转交页面内容。

**修复**

在许可范围内提供正文、导出文件或公开镜像；否则让 Agent 保留“无法确认”状态。

**恢复验证**

Agent 能引用你提供的完整材料，并明确其证据来源，不再把标题或搜索摘要当全文。

## 视频或仓库下载占用过多磁盘

**常见原因**

- 下载前没有估算体积；
- 临时文件写进系统盘、home 或桌面；
- 仓库包含大文件或完整历史。

**安全检查**

先查看目标盘余量和预计下载规模。不要通过删除未知文件来腾空间。

**修复**

改用有空间的专用暂存盘；若空间不足，停止下载并报告边界。

**恢复验证**

目标盘空间足够，下载路径明确，任务结束后临时文件的所有权和去留清楚。

## 输出总是落到“存档、做内容或变现”

**常见原因**

- Agent 沿用了其他工作流的默认目标；
- 没有执行 `kenton-link-lens` 的红线约束。

**安全检查**

检查回答是否遗漏技术启发、产品机制、认知判断、风险或跨域连接。

**修复**

要求 Agent 回到对象本身，补充至少一个不依赖内容生产或变现的非显然洞察。

**恢复验证**

结论覆盖对象成色、机制、风险、可迁移模式和具体行动，而不是只给归档建议。
